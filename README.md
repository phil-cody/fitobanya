# Каталог бань и саун
## Демо

https://phil-cody.github.io/fitobanya/


Многостраничный frontend-каталог товаров для сайта о саунах, фитобочках и оборудовании. Репозиторий содержит страницы каталога, карточки товара, корзины, поиска, информации о доставке и контактах.

## Что реализовано

- адаптивные страницы каталога и товара;
- интерактивные элементы интерфейса: меню, фильтры, слайдеры, вкладки и аккордеоны;
- формы обратной связи и заявки;
- отдельные страницы доставки, отзывов, политики обработки данных и состояния заказа.

## Стек

HTML, CSS/SCSS, JavaScript.

Это frontend-проект: серверная логика магазина и обработка заказов в репозитории не представлены.
