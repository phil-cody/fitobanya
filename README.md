# Каталог бань и саун

**Демо:** https://phil-cody.github.io/fitobanya/

Многостраничный frontend-каталог бань, саун и оборудования. Проект включает страницы каталога и товара, корзину, поиск, информацию о доставке, контакты и другие разделы.

## Что реализовано

- адаптивные страницы каталога и товара;
- интерактивные элементы интерфейса: меню, фильтры, слайдеры, вкладки и аккордеоны;
- интерфейс корзины, поиска и фильтрации каталога;
- отдельные страницы доставки, отзывов, политики обработки данных и состояния заказа.

## Стек

HTML, CSS/SCSS, JavaScript.

Это демонстрационный frontend: серверная логика магазина, отправка заявок и обработка заказов в репозитории не представлены.

## Локальный запуск

Откройте `index.html` в браузере или запустите локальный HTTP-сервер из корня проекта:

```bash
python3 -m http.server 8000
```
